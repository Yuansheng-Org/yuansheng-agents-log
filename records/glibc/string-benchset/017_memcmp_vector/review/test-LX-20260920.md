# `017_memcmp_vector` 在 LX 的隔离测试

测试日期：2026-09-20（Asia/Shanghai）

## 结论

- correctness：`make test t=string/test-memcmp` 通过。
- 491 个 benchmark case 的 generic 归一化几何平均为提升 **45.57%**。
- 322 个 mismatch case 的归一化几何平均为提升 **60.42%**；但并非全部 case 提升，235 个提升、87 个回退。
- 长尺寸存在明确回退：65–256 的 mismatch case 几何平均回退 **12.13%**，>256 的 mismatch case 回退 **38.51%**。
- 169 个 equal case 的归一化结果为提升 **0.11%**，可作为本轮测量噪声控制。

因此，这份补丁在当前目标机上 correctness 正常，且短尺寸收益很大，但长尺寸 mismatch 回退明显，不能只依据 overall 数字判断为无条件收益。

## Performance 方法

只构建并运行 `bench-memcmp`，没有运行完整 `make bench`。glibc 顶层 `make bench t=...` 会忽略 `t` 并展开完整 bench，因此本次直接构建单个二进制，并通过各 build 的 `testrun.sh` 启动：

```sh
taskset -c 2 BUILD/testrun.sh BUILD/benchtests/bench-memcmp
```

- baseline 和 patched 各预热 1 次。
- 正式各运行 6 次。
- 固定 CPU 2。
- 奇数轮顺序为 baseline → patched，偶数轮为 patched → baseline。
- 每份输出均用 `python3 -m json.tool` 校验。
- 每个 case 先分别取 6 次 timing 的中位数，再计算：

```text
(patched vector / patched generic) /
(baseline vector / baseline generic)
```

表中的提升为 `(1 - ratio) * 100`；负数表示回退。
